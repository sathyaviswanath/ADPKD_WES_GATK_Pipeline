# ADPKD Whole Exome Sequencing Pipeline Overview

## Project Overview

This project implements a complete **Whole Exome Sequencing (WES) analysis pipeline** for **Autosomal Dominant Polycystic Kidney Disease (ADPKD)** using the public sample **SRR21384731**.

The workflow follows **GATK Best Practices** for variant discovery and extends beyond variant calling by performing **functional annotation, candidate variant prioritization, visualization, summary statistics, and automated clinical report generation**.

---

## Dataset

**Sample:**  
SRR21384731

**Sequencing Platform:**  
Illumina Paired-End Whole Exome Sequencing

**Disease:**  
Autosomal Dominant Polycystic Kidney Disease (ADPKD)

---

## Reference Resources

- **Reference Genome:** GRCh38
- **Target Genes:** PKD1 and PKD2
- **Variant Annotation:** Ensembl VEP
- **Population Frequency Database:** gnomAD
- **Clinical Database:** ClinVar

# Pipeline Workflow

```text
Raw FASTQ
      │
      ▼
Quality Control
(FastQC, FastP)
      │
      ▼
Read Alignment
(BWA-MEM)
      │
      ▼
BAM Processing
(SAMtools)
      │
      ▼

(GATK BQSR)
      │
      ▼

(GATK HaplotypeCaller)

      ▼
Variant Filtering
      │
      ▼

      │
      ▼
Variant Prioritization
      │
      ▼
Summary Statistics
      │
      ▼
Visualization
      │
      ▼
Clinical Report Generation
```

# Pipeline Components

## 1. Quality Control

**Tools Used**

- FastQC
- FastP

Performs sequencing quality assessment and read trimming before alignment.

---

## 2. Read Alignment

**Tool Used**

- BWA-MEM

Maps sequencing reads against the **GRCh38** human reference genome.

---

## 3. BAM Processing

**Tool Used**

- SAMtools

Performs:

- Sorting
- Indexing
- Duplicate removal
- Preparation for downstream variant calling

---

## 4. Variant Calling

**Tools Used**

- GATK HaplotypeCaller
- GATK VariantFiltration

Identifies high-confidence SNPs and small insertions/deletions (INDELs).

---

## 5. Variant Annotation

**Tool Used**

- Ensembl Variant Effect Predictor (VEP)

Each variant is annotated with:

- Gene symbol
- Transcript
- Functional consequence
- Variant impact
- Canonical transcript
- MANE transcript
- PolyPhen prediction
- gnomAD allele frequency
- ClinVar clinical significance

---

## 6. Candidate Variant Prioritization

Candidate variants are prioritized using:

- PKD1 and PKD2 genes
- Canonical transcripts
- MANE Select transcripts
- Functional consequence
- PolyPhen prediction
- Population allele frequency (gnomAD)
- Clinical significance (ClinVar)

---

## 7. Summary Report

A Python script automatically generates a concise summary containing:

- Total variants detected
- PKD gene variants
- Candidate variants
- Canonical candidate variants
- High-priority variants

---

## 8. Visualization

Publication-ready figures are automatically generated:

- Interpretation Distribution
- Consequence Distribution
- Impact Distribution
- Canonical Transcript Distribution
- PKD1 vs PKD2 Variant Distribution

---

## 9. Clinical Report

A concise clinical report is automatically generated including:

- Sample information
- Pipeline summary
- Top candidate variants
- Generated figures
- Clinical conclusion

# Project Outcome

This project demonstrates an end-to-end **Whole Exome Sequencing (WES)** workflow for **Autosomal Dominant Polycystic Kidney Disease (ADPKD)**. It integrates **variant discovery, functional annotation, candidate variant prioritization, visualization, summary statistics, and automated clinical reporting** into a reproducible bioinformatics pipeline.

The project showcases practical skills in **NGS data analysis**, **clinical genomics**, **Python automation**, and **variant interpretation**, making it suitable as a portfolio project for entry-level bioinformatics and clinical genomics roles.
